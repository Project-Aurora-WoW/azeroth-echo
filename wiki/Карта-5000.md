# Карта 5000 «CustomMaps»

Кастомная карта проекта: два региона, собранные из тайлов `.adt`.

## Регионы

| Регион | Тайлы | Координаты телепорта |
|---|---|---|
| Остров Морза | 25–26 / 57–58 | `.go xyz -13950 2877 9 5000` |
| Долина Предательства | 48–50 / 12–14 | `.go xyz 10461 -9574 22 5000` |

## Лор-привязка

- **Морза** — флотский перевал Культа Усмешки Бездны. Упоминается Портальным Стражем (entry 70001).
- **Долина Предательства** — тайный перевалочный пункт Культа, где эхо разлома искажает мысли тех, кто задерживается дольше суток.

## Состав `patch-Z.mpq`

| Файл | Размер | Назначение |
|---|---|---|
| `DBFilesClient\Map.dbc` | 43 523 б | запись карты 5000 в клиенте |
| `World\Maps\CustomMaps\CustomMaps.wdt` | 32 844 б | описание карты |
| `.adt` × 10 | 13.5 МБ | тайлы регионов |

Собранный архив — **2 676 286 б**.

## Почему `Map.dbc` только в `patch-Z`

Клиент грузит `patch-*.mpq` по алфавиту, и последний полностью перекрывает предыдущие по совпадающим файлам:

```
patch-2 → patch-3 → patch-x → patch-Z
```

Если положить `Map.dbc` и в `patch-x`, и в `patch-Z`, выживет версия из `patch-Z` — но при добавлении своих карт в `patch-x` они молча исчезнут. Поэтому правило: **`Map.dbc` живёт только в `patch-Z`**.

Когда понадобится добавить карту, мерджить нужно на базе `Map.dbc` из `patch-Z`, а имя патча брать по алфавиту **после** `Z`: `patch-Z2.mpq`, `patch-0.mpq`. Имя `patch-y` не подойдёт — `y` < `z`.

## Серверная часть

`Map.dbc` нужен и серверу: он лежит в `data/dbc/` рядом с `worldserver.exe`.

```
E:\acbuild\bin\RelWithDebInfo\data\dbc\Map.dbc
```

Если сервер не видит карту 5000, `.go xyz ... 5000` вернёт ошибку «map not found» и клиент, скорее всего, дисконнектится.

## Повреждение оригинального архива

Исходный `patch-Z.MPQ` из репозитория `custom-maps` (3 209 747 б) **нечитаем**: заголовок содержит `hash_table_size = 3144003`, `hash_table_offset = 4096`, `block_table_offset = 13` — ни одна 16-байтная запись не имеет валидных флагов `0x80xxxxxx`, все `start+csize` выходят за пределы файла. Перебор размеров хеш-таблицы и выравненных смещений валидную таблицу не нашёл.

Архив в релизе собран заново из распакованных `.adt`/`.wdt`/`Map.dbc` тем же сборщиком, что и `patch-x`:

```bash
python tools/dbc/build_z.py
```

## Проверка архива

```bash
python tools/dbc/verify_mpq.py
```

Скрипт дешифрует хеш- и block-таблицы, распаковывает каждый блок и сверяет размеры с `fsize`. Для `patch-Z` ожидаемый результат — **13/13 блоков корректны**.

## Ограничения

Карта не проверялась в игре. Валидность подтверждается только успешной распаковкой блоков — это доказывает целостность файлов, но не рендер, коллизии и навигацию. Первый вход на карту 5000 — единственный настоящий тест.
