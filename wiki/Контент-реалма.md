## Диапазоны ID

Чтобы не пересекаться с базовым ACDB и модулями, заняты следующие диапазоны:

| Диапазон | Назначение |
|---|---|
| `70001–70199` | НПС и предметы проекта |
| `70100–70199` | Waloria-награды, награды уровней |
| `70200–70999` | резерв кампаний |
| `705605` | gameobject Алтаря Испытаний |
| `990001–991999` | модуль Archivist |
| `70010` (spell) | спелл маунта |
| `178` (title) | титул «Хранитель Эха» |

## Титул «Хранитель Эха»

| Параметр | Значение |
|---|---|
| ID | 178 |
| Мужской | «Хранитель Эха» |
| Женский | «Хранительница Эха» |
| Маска (`Mask_ID`) | 6727 |
| Клиент | `CharTitles.dbc` в `patch-x.mpq` |
| Сервер | `chartitles_dbc` в `echo_world` |

Выдача из Lua после завершения кампании 3:

```lua
player:SetTitle(178)
```

Штатный диапазон титулов WoW — 1–47. ID 178 находится вне его, поведение эмпирическое. Если титул не отображается у персонажа, потребуется пересборка с ID внутри штатного диапазона.

## Спелл «Призыв: Бездна-Пегас»

| Параметр | Значение |
|---|---|
| ID | 70010 |
| Шаблон | клон спелла 45991 |
| Имя enUS | `Summon: Voidrest Pegasus` |
| Категория | 76 (маунты) |
| Клиент | `Spell.dbc` в `patch-x.mpq` |
| Сервер | `spell_dbc` в `echo_world` |

Привязка к предмету:

```sql
UPDATE item_template
SET spellid_1=70010, spelltrigger_1=0, spellcategory_1=76, spellcategorycooldown_1=-1
WHERE entry=70003;
```

Имя спелла в клиенте только на enUS: отдельного ruRU-слота для `SpellName` в структуре `Spell.dbc` нет.

## Режимы испытаний

Алтарь Испытаний (gameobject **705605**) открывает меню выбора режима. Реализация — модуль `echo-challenge-modes`, класс `altar_challenge_modes`.

Доступные режимы:

| Режим | Эффект |
|---|---|
| Hardcore | смерть окончательна, воскрешение запрещено |
| Semi-Hardcore | штрафы вместо окончательной смерти |
| Self-Crafted | нельзя использовать чужие предметы |
| Item Quality Level | ограничение по качеству экипировки |
| Slow XP | пониженный множитель опыта |
| Very Slow XP | сильно пониженный |
| Quest XP Only | опыт только за квесты |
| Iron Man | без смертей и без торговли |

Настройка — `configs/modules/echo-challenge-modes.conf`.

## Проверка контента на живом сервере

Через SOAP (см. [SOAP и администрирование](SOAP-и-администрирование)):

```
lookup item Печать        → 70002
lookup item Бездна        → 70003
lookup item Пустоты       → 70004, 70008
lookup creature Портальный → 70001
lookup spell Voidrest     → 70010
lookup title Echo         → 178
```

Оговорка: `lookup item 70002` по числу не находит — команда ищет по ID в базовом диапазоне; поиск по имени работает.
