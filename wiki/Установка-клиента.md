# Установка клиента

Как поставить патчи реалма и попасть в игру.

## Требования

| Компонент | Значение |
|---|---|
| Клиент WoW | **3.3.5a, build 12340** |
| Локаль | ruRU, enGB или enUS |
| Место на диске | ~15 МБ сверх клиента |

Другой билд не подойдёт: патчи собраны под 12340, на других версиях клиент не запустится или не покажет контент.

## Шаг 1. Скачать файлы

Со страницы релиза: **[v1.0.0](https://github.com/Project-Aurora-WoW/azeroth-echo/releases/tag/v1.0.0)**

| Файл | Размер | SHA256 (первые 16) |
|---|---|---|
| `patch-x.mpq` | 4 120 622 б | `ad4377dd90f13fc9` |
| `patch-Z.mpq` | 2 676 286 б | `26310a6bb35c3cc5` |
| `AzerothEcho.zip` | 9 217 б | `0e0630725312014b` |

Проверить целостность:

```powershell
Get-FileHash .\patch-x.mpq -Algorithm SHA256
```

## Шаг 2. Установить патчи

```
WoW/
├── Data/
│   ├── patch-2.MPQ          (штатный)
│   ├── patch-3.MPQ          (штатный)
│   ├── patch-x.mpq          ← скопировать сюда
│   └── patch-Z.mpq          ← скопировать сюда
```

Клиент загружает `patch-*.mpq` **по алфавиту**, более поздний полностью перекрывает ранний по совпадающим файлам:

```
patch-2 → patch-3 → patch-x → patch-Z
```

`patch-Z` стоит последним намеренно: его `Map.dbc` описывает карту 5000 и должен побеждать.

## Шаг 3. Установить аддон

`AzerothEcho.zip` распаковать так, чтобы получилось:

```
WoW/Interface/AddOns/AzerothEcho/
├── AzerothEcho.toc
├── AzerothEcho.lua
├── Core.lua
├── Panel.lua
└── RiftMap.lua
```

Не должно быть вложенной папки `AzerothEcho/AzerothEcho/` — это частая ошибка при распаковке архивов.

## Шаг 4. Очистить кэш

**Обязательно.** Клиент кэширует DBC в `Cache/WDB/` и после смены патчей продолжает читать старые данные.

```powershell
Remove-Item -Recurse -Force "C:\WoW\Cache\WDB\ruRU"
```

Или удалить каталог `Cache/WDB/` целиком — он пересоздастся.

## Шаг 5. Прописать реалм

Файл `WoW/Data/ruRU/realmlist.wtf` (или `enUS`):

```
set realmlist <адрес сервера>
```

Для локального сервера: `set realmlist 127.0.0.1`.

## Шаг 6. Запуск

`Wow.exe`. Аддон включён по умолчанию (`## DefaultState: enabled` в TOC).

## Проверка, что всё работает

Войдя в игру персонажем с правами GM:

```
.additem 70002                      → Печать Хранителя Эха (даёт титул)
.additem 70003                      → Бездна-Пегас (маунт)
.go xyz -13950 2877 9 5000          → Остров Морза
.go xyz 10461 -9574 22 5000         → Долина Предательства
```

Проверка титула: правый клик по персонажу → вкладка «Титулы» → должен быть «Хранитель Эха».

## Автоматическая установка лаунчером

В репозитории есть PowerShell-скрипт, который сверяет файлы по манифесту и докачивает отличия:

```powershell
.\client\update-client.ps1 -WowDir "C:\WoW" -PatchUrl "https://github.com/Project-Aurora-WoW/azeroth-echo/releases/download/v1.0.0"
```

Что делает скрипт:

1. Читает `manifest.json` (версия 5).
2. Для каждого файла считает локальный SHA256 и сравнивает с манифестом.
3. Докачивает только отличающиеся — по полю `url` из манифеста.
4. Чистит `Cache/WDB`.
5. Прописывает `realmlist`.
6. Запускает `Wow.exe`.

## Если что-то не так

| Симптом | Причина |
|---|---|
| Клиент падает на загрузке | битый MPQ или неверный порядок загрузки |
| Титул не отображается | не очищен `Cache/WDB`, или ID титула не подошёл |
| Маунт не призывается | спелл 70010 отсутствует в клиентском `Spell.dbc` |
| Карта 5000 не грузится, дисконнект | нет `patch-Z.mpq` в `Data/` |
| Аддон не виден | вложенная папка при распаковке |

Подробнее — [Устранение неполадок](Устранение-неполадок).
