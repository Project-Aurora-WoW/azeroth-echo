# Установка сервера

Развёртывание серверной части с нуля.

## Что понадобится

| Компонент | Версия | Примечание |
|---|---|---|
| Windows | 10/11 x64 | проверено на 10.0.26200 |
| Visual Studio Build Tools | 18 (2026) | MSVC 19.51+ |
| CMake | 4.5+ | |
| MySQL | 8.0.46 | на порту 3306 |
| Boost | 1.78 | `C:\local\boost_1_78_0` |
| OpenSSL | 4.0.3 | `C:\Program Files\OpenSSL-Win64` |
| Клиент 3.3.5a | build 12340 | источник DBC и карт |

## Шаг 1. Исходники

```powershell
git clone https://github.com/Project-Aurora-WoW/azeroth-echo-core.git E:\azeroth
```

Каталог `data/sql` в репозиторий не входит — его берут из апстрима AzerothCore:

```powershell
git clone --depth 1 https://github.com/azerothcore/azerothcore-wotlk.git C:\temp\ac
Copy-Item -Recurse C:\temp\ac\data\sql E:\azeroth\data\
```

Без этого `worldserver` не сможет применять автообновления и упадёт с `Failed to initialize network`.

## Шаг 2. Сборка

```powershell
cmake -S E:/azeroth -B E:/acbuild -G "Visual Studio 18 2026" -A x64 `
      -DCMAKE_INSTALL_PREFIX=E:/acbuild/bin -DSCRIPTS=static

cmake --build E:/acbuild --config RelWithDebInfo --target worldserver authserver --parallel
```

Результат: `E:\acbuild\bin\RelWithDebInfo\worldserver.exe` и `authserver.exe`.

Подробнее о модулях и типичных ошибках сборки — [Сборка ядра](Сборка-ядра).

## Шаг 3. Данные клиента

В каталог `E:\acbuild\bin\RelWithDebInfo\data\` нужны:

```
data/
├── dbc/       ← DBC-файлы (ruRU, enUS)
├── maps/
├── vmaps/
└── Cameras/
```

Готовые можно взять из `E:\b2\bin\RelWithDebInfo\data`, если там уже есть рабочая установка, или извлечь из клиента экстракторами (`map_extractor.exe`, `vmap4_extractor.exe`, `mmaps_generator.exe`).

## Шаг 4. Базы данных

```sql
CREATE DATABASE echo_world      CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE echo_characters CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE DATABASE echo_auth       CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Схема снимается с рабочей установки AzerothCore:

```powershell
mysqldump -u root -p --no-data --skip-add-drop-table --databases acore_world acore_characters acore_auth `
  --result-file=backup_schema.sql
```

Затем в дампе заменить имена баз на `echo_*` и залить:

```powershell
Get-Content backup_schema.sql | mysql -u root -p
```

## Шаг 5. Базовый мир

`echo_world` должна получить базовый контент ACDB (около 30 тыс. НПС, 46 тыс. предметов):

```powershell
mysqldump -u root -p --single-transaction --quick --hex-blob `
  --databases acore_world --result-file=base_world.sql
```

В дампе заменить `USE acore_world` на `USE echo_world`, `CREATE DATABASE ... acore_world` на `echo_world`, затем:

```powershell
Get-Content base_world.sql | mysql -u root -p --default-character-set=utf8mb4
```

Аналогично для `characters` и `auth`.

## Шаг 6. Миграции проекта

Использовать **`sql/world-adapted/`**, не `sql/world/` — исходные падают на схеме этого ядра.

```powershell
$dir = "E:\azeroth-echo\sql\world-adapted"
Get-ChildItem $dir -Filter *.sql | Sort-Object Name | ForEach-Object {
    Get-Content $_.FullName -Raw | mysql -u root -p --default-character-set=utf8mb4
}
```

Порядок обязателен: `0001` → `0021`. Подробности — [SQL-миграции](SQL-миграции).

## Шаг 7. Конфиги

Из `configs/*.conf.dist` создать рабочие копии и прописать:

**worldserver.conf**
```ini
LoginDatabaseInfo     = "127.0.0.1;3306;USER;PASS;echo_auth"
WorldDatabaseInfo     = "127.0.0.1;3306;USER;PASS;echo_world"
CharacterDatabaseInfo = "127.0.0.1;3306;USER;PASS;echo_characters"
DataDir               = "data"
WorldServerPort       = 8085
SOAP.Enabled          = 1
SOAP.IP               = "127.0.0.1"
SOAP.Port             = 7878
Appender.Console      = 1,4,0,"1 9 3 6 5 8"
```

**authserver.conf**
```ini
LoginDatabaseInfo = "127.0.0.1;3306;USER;PASS;echo_auth"
RealmServerPort   = 3724
```

Ловушка: `Appender.Console` должен начинаться с **`1`** (тип appender). Значение `4` даёт `Unknown type '4' for appender Console` и сервер молча выходит.

## Шаг 8. Realmlist

```sql
UPDATE echo_auth.realmlist
SET address='127.0.0.1', localAddress='127.0.0.1', port=8085, gamebuild=12340
WHERE id=1;
```

## Шаг 9. Запуск

```powershell
cd E:\acbuild\bin\RelWithDebInfo
.\authserver.exe -c configs/authserver.conf
.\worldserver.exe -c configs/worldserver.conf
```

Флаг `-c` обязателен: по умолчанию `worldserver` ищет конфиг в текущем каталоге, а он лежит в `configs\`.

Признак успеха в логе:

```
Opening DatabasePool 'echo_world' ... opened successfully
Updating World database... >> World database is up-to-date!
WORLD: World Initialized In 0 Minutes 10 Seconds
worldserver-daemon ready...
```

## Шаг 10. Аккаунт

Через консоль `worldserver` или SOAP:

```
account create MYACC mypassword
account set gmlevel MYACC 3 -1
```

## Порядок остановки и запуска

Останавливать: сначала `worldserver`, потом `authserver`. Запускать наоборот — `authserver`, затем `worldserver`.

Если запустить `worldserver` без `authserver`, он поднимется, но клиенты не смогут авторизоваться.
